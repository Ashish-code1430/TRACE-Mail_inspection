# TRACE-Mail

Email Threat Explanation Assistant using Deep Learning and NLP.

## Features
- Email text classification
- Email header analysis
- Suspicious URL detection
- Rule-based threat indicators
- Explainable forensic reports

## Technology Stack
- Python
- PyTorch
- DistilBERT
- Hugging Face Transformers
- Gradio

## Setup
Install dependencies using `pip install -r requirements.txt`.

The trained model files are not included in this initial repository setup. Configure the model directory before running the application.

## Disclaimer
This tool provides automated indicators, not a guarantee that an email is safe or malicious.
